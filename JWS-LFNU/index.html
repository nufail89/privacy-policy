JWS LFNU JATIM · Privasi Anda

Kebijakan Privasi

Penjelasan mengenai informasi yang digunakan aplikasi, cara pemrosesannya, dan pilihan yang tersedia bagi Anda.

Berlaku sejak 26 November 2026

Ringkasnya: JWS LFNU JATIM membantu Anda mengatur perangkat JWS. Pengaturan disimpan di perangkat Anda dan dapat dikirim langsung ke controller ESP yang Anda pilih. Aplikasi tidak mengoperasikan akun pengguna untuk menyimpan pengaturan tersebut.

1. Tentang kebijakan ini

Kebijakan ini menjelaskan informasi yang diproses ketika Anda menggunakan aplikasi JWS LFNU JATIM (“Aplikasi”), termasuk fitur lokasi, pengaturan JWS, dan koneksi ke controller ESP. Jika Anda tidak ingin menggunakan fitur tertentu, Anda dapat menolak izin opsional atau tidak mengisi informasi yang diminta. Fitur terkait mungkin tidak tersedia jika informasi atau izin tersebut diperlukan.

2. Informasi yang digunakan

Bergantung pada fitur yang Anda gunakan, Aplikasi dapat memproses:

  • Informasi lokasi: koordinat lintang dan bujur, ketinggian, zona waktu, dan nama wilayah yang dicari dari koordinat. Lokasi dapat dimasukkan sendiri atau diperoleh dari perangkat setelah Anda menggunakan fitur lokasi.
  • Pengaturan JWS: misalnya nama dan alamat masjid, informasi tampilan, pengaturan waktu sholat, adzan dan iqomah, jadwal Jumat, muadzin, imam, pengaturan alarm, serta informasi kas masjid jika Anda mengisi fitur tersebut.
  • Pengaturan perangkat: alamat IP controller, informasi koneksi, serta pengaturan LED, murottal, alarm, dan Wi-Fi yang Anda masukkan. Pengaturan Wi-Fi dapat mencakup nama jaringan (SSID) dan kata sandinya.
  • Informasi controller: status keterjangkauan controller dan data konfigurasi yang dikembalikan oleh controller, yang dapat mencakup nomor seri perangkat jika tersedia.
  • File yang Anda pilih: file konfigurasi atau firmware yang Anda pilih untuk dimuat, disimpan, atau dikirim ke controller.
  • Status jaringan: informasi konektivitas yang digunakan untuk menampilkan status jaringan dan membantu komunikasi dengan controller.

3. Lokasi dan izin

Jika Anda menggunakan fitur untuk mendapatkan koordinat otomatis, Aplikasi meminta izin lokasi presisi atau perkiraan melalui dialog izin sistem operasi. Sebelum permintaan izin tersebut, Aplikasi menjelaskan tujuan penggunaan lokasi dan meminta persetujuan Anda.

Lokasi digunakan saat Anda menjalankan fitur lokasi ketika Aplikasi sedang digunakan, untuk mengisi koordinat, ketinggian, dan zona waktu pada pengaturan JWS. Aplikasi tidak menjalankan pelacakan lokasi latar belakang. Anda dapat menolak izin dan memasukkan koordinat secara manual; fitur yang memerlukan lokasi otomatis mungkin tidak berfungsi.

Untuk mencari nama wilayah dari koordinat, Aplikasi menggunakan layanan geocoding yang disediakan melalui platform perangkat. Koordinat yang diperlukan untuk pencarian dapat diproses oleh penyedia layanan tersebut sesuai kebijakan privasinya. Nama wilayah dan koordinat hasil pencarian dapat disimpan sebagai cache lokal agar pencarian tidak perlu diulang.

4. Penyimpanan dan pengiriman informasi

  • Beberapa pengaturan, data lokasi terakhir, cache nama wilayah, dan informasi Wi-Fi disimpan secara lokal pada perangkat Anda agar dapat dimuat kembali oleh Aplikasi.
  • Saat Anda menyimpan atau menggunakan fitur kontrol, data yang diperlukan dikirim dari Aplikasi ke alamat IP controller ESP yang Anda atur. Controller dapat menyimpan data tersebut di perangkatnya.
  • Komunikasi Aplikasi dengan controller menggunakan HTTP pada jaringan lokal dan tidak dienkripsi oleh Aplikasi. Ini termasuk pengiriman pengaturan Wi-Fi apabila Anda memilih untuk mengirimkannya ke controller. Gunakan jaringan yang Anda percayai.
  • File konfigurasi yang diekspor disimpan ke lokasi yang Anda pilih. File firmware yang Anda pilih dikirim ke controller hanya ketika Anda memulai proses pembaruan.
  • Pengembang tidak menerima pengaturan JWS melalui server akun atau server pusat Aplikasi. Layanan eksternal yang digunakan oleh platform atau tautan yang Anda buka dapat memproses informasi sesuai kebijakan mereka masing-masing.

5. Tujuan penggunaan

Informasi digunakan untuk:

  • mengisi dan menyimpan pengaturan perangkat JWS;
  • mengirim konfigurasi atau perintah ke controller ESP pilihan Anda;
  • menampilkan status koneksi controller dan jaringan;
  • mencari nama wilayah untuk koordinat yang digunakan; dan
  • memuat, menyimpan, atau mengirim file yang Anda pilih.

Aplikasi tidak menggunakan lokasi untuk pelacakan latar belakang atau iklan bertarget.

6. Layanan pihak ketiga dan tautan

Aplikasi dapat menggunakan layanan geocoding platform untuk mencari nama wilayah. Aplikasi juga dapat membuka WhatsApp untuk menghubungi dukungan, serta membuka tautan eksternal untuk memperoleh firmware. Ketika Anda menggunakan layanan atau tautan tersebut, penyedia terkait dapat memproses informasi sesuai kebijakan privasinya sendiri. Pengembang tidak mengendalikan praktik privasi layanan eksternal.

7. Penyimpanan dan penghapusan

Data lokal Aplikasi dapat dihapus dengan menghapus data Aplikasi melalui pengaturan perangkat atau menghapus instalasi Aplikasi. File konfigurasi yang Anda ekspor tetap berada di lokasi penyimpanan yang Anda pilih sampai Anda menghapusnya. Data yang telah dikirim ke controller dapat tetap tersimpan di controller sampai diubah atau dihapus melalui perangkat tersebut.

8. Keamanan

Aplikasi mengandalkan perlindungan perangkat dan sistem operasi untuk data yang disimpan secara lokal. Komunikasi HTTP ke controller tidak dienkripsi oleh Aplikasi. Lindungi perangkat, file cadangan, kredensial Wi-Fi, controller, dan jaringan lokal Anda. Hindari mengirim informasi sensitif melalui jaringan yang tidak tepercaya.

9. Anak-anak

Aplikasi merupakan alat pengaturan perangkat JWS dan tidak dirancang untuk mengumpulkan informasi pribadi anak-anak. Orang tua atau wali dapat menghubungi pengembang melalui alamat di bagian Kontak jika memiliki pertanyaan tentang informasi yang diproses oleh Aplikasi.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui apabila fitur atau cara pemrosesan informasi berubah. Versi terbaru akan dipublikasikan di halaman ini dengan tanggal berlaku yang diperbarui. Silakan periksa halaman ini secara berkala.
